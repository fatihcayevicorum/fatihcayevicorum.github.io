# FatihKazan ESP32 FW 0.6.7 — Bildirim telemetrisi düzeltme adayı (R665)
0.6.5'in sahada çalışan I0-öncelikli okuma sırası, 0.6.6'nın bildirim veri sözleşmesi ile birleştirilir. I2 hata register'ı normal okumaları tamamladıktan sonra ayrı okunur. I2 okunamazsa geçerli I0 ölçümü (−50…200 °C mevcut sunucu sınırı) korunur; doğrulanmamış hata kodu gönderilmez. I2 1–5 dönerse sıcaklık/ayar ölçümleri geçersiz sayılır, ENDA iletişim durumu ve doğrulanmış hata kodu gönderilir; önceden doğrulanmış hata yeni I2=0 okunana kadar temizlenmez. I0 ve I2 birlikte geçerli bilgi vermezse sahte değer üretilmez. Sunucunun mevcut sözleşmesi doğrulanmamış I2 durumunu ayrı alan olarak göstermiyor; gönderilmeyen kod sunucuda 0 kabul edilir. I2 okunamadığında gerçek sensör arızası bildirimi garanti edilemez.
Kaynak: ENDA ETx420 Modbus bellek haritası, I0 ve I2, s.6: https://enda.com/en/automation/temperature-controllers/et4420/etx420.pdf
Mevcut hedef, ON/OFF, H35, C6, tek-sefer yazma, OTA doğrulama, Wi-Fi, PIN ve şifreli yayın akışları değiştirilmedi. Yeni Modbus yazması eklenmedi. Default flash düzeni ve 0x140000 OTA alanı korunur. GitHub smoke build gizli olmayan test başlıklarıyla derlenir; cihazda kullanılmaz. Gerçek bin yalnız main üzerinde yetkili manual workflow ile gizli yapılandırma kullanılarak üretilip güvenli Firebase yoluna hazırlanır. Açık depoya çıplak bin veya cihaz anahtarı konmaz.
Fiziksel doğrulama: kazan güvenli kapalı durumdayken önce normal sıcaklık/ayar/çıkış verisini karşılaştır, ardından uygun kontrollü masa testinde I2 hata ve düzelme senaryolarını doğrula. Fiziksel cihaz ve gerçek OTA testi yapılmadan onaylı firmware sayma.
